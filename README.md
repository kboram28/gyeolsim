# gyeolsim (결심) — 일정·할 일 코치 PWA

캘린더, 코치가 재촉하고 칭찬하는 할 일 목록, 하루 목표를 채우면 김결 포토카드·새 영상이 열리는 보상 기능이 있는 개인용 웹앱이에요.
서버도 로그인도 없고, 모든 데이터는 **내 아이폰 Safari 저장소에만** 저장돼요.

## 파일 구성
```
index.html     앱 전체 (화면 + 기능)
manifest.json  홈 화면 앱 이름·아이콘 설정
sw.js          오프라인 지원 (서비스 워커)
icons/         홈 화면 아이콘
data/          포토카드 목록(cards.json, 직접 검수한 292장)과 김결 채널 영상 목록(videos.json)
tools/photocards/  새 영상이 쌓였을 때 포토카드를 다시 검수하는 도구
push/          코치 알림 + 최신 영상 목록 서버 (Cloudflare Worker)
```

## 1. GitHub Pages로 배포하기 (무료)
1. GitHub에서 새 저장소를 만들어요 (예: `gyeolsim`).
2. 이 폴더 안의 파일을 **폴더 구조 그대로** 업로드해요. (`index.html`이 저장소 맨 위에 있어야 해요.)
3. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 선택하고 저장해요.
4. 1~2분 뒤 `https://<내아이디>.github.io/gyeolsim/` 주소가 생겨요.

> 무료 계정의 GitHub Pages는 공개 저장소에서 쓰는 게 기본이라 **코드는 공개**돼요.
> 하지만 할 일·일정·사진 같은 **데이터는 폰 안에만 저장**되기 때문에 다른 사람에게 보이지 않아요.
> 코드도 숨기고 싶다면 Netlify Drop(https://app.netlify.com/drop)에 폴더를 끌어다 놓는 방법도 있어요.

## 2. 아이폰에 설치하기
1. 아이폰 **Safari**로 배포 주소에 접속해요. (크롬 앱이 아니라 Safari로 여는 걸 추천해요.)
2. 아래쪽 **공유 버튼(□↑)** → **홈 화면에 추가**를 눌러요.
3. 홈 화면의 'gyeolsim' 아이콘으로 실행하면 주소창 없이 앱처럼 열려요.

## 3. 처음 설정
- **설정** 탭에서 내 이름, 최애 가수, 코치 스타일(다정 / 밀당 / 호랑이)을 정해요.
- **오늘 목표**는 따로 정하지 않아요. 오늘 마감인 할 일과 오늘 끝낸 할 일 개수가 그날의 목표가 돼요. 루틴은 목표·보상에 들어가지 않아요. (미리 끝낸 일도 목표에 더해져요)
- **테마**: 포인트 색과 배경 사진(포토카드 또는 내 사진)을 골라요. 포인트 색은 + 버튼으로 원하는 색(색상 코드)을 12개까지 등록할 수 있어요. 배경 사진은 홈·김결 탭 맨 위와 할 일 코치 카드에 보여요.
- **김결 탭 → 프로필**에서 덕질 시작일, 생일, 데뷔일을 넣어요.
- **프로젝트** 탭에서 한 달짜리 같은 긴 목표를 만들고 세부 할 일을 넣으면 진행률(%)과 기간 경과율이 함께 보여요. 진행률이 기간보다 15%p 이상 밀리면 '뒤처짐'으로 표시되고 코치가 재촉해요.
- **캘린더**에서 생일·공연 같은 가수 일정을 '가수 일정'으로 등록하면 캘린더 맨 위에 D-day 티켓이 떠요.

## 탭 구성
- **홈**: 오늘 목표 달성률, 오늘의 루틴, 오늘 할 일, 이번 달 프로젝트 진행률, 오늘 일정만 간단히 보여 줘요.
- **캘린더**: 일정과 프로젝트 마감만 다뤄요. 일정은 카테고리별 색상으로 표시돼요. 날짜를 누르면 그날 일정이 창으로 뜨고, 거기서 바로 일정을 추가할 수 있어요. 달력 아래에는 앞으로 한 달의 일정이 보여요.
- **반복 일정**: 일정 추가 창의 '반복'에서 매주(요일 여러 개, 끝나는 날 선택)나 매년을 고를 수 있어요.
- **일정 바꾸기**: 날짜 창에서 일정을 누르면 수정·삭제할 수 있어요. 반복 일정은 세 가지 중에 골라서 바꾸거나 지워요: '그 날 하루만'(휴강·시간 변경), '이 날부터 앞으로'(바뀌는 날을 골라 그 전 일정은 그대로 두고 새 요일·시간으로 이어감), '지난 일정까지 전부'.

## 오늘의 보상
오늘 목표를 채우면 홈의 '오늘의 보상' 카드가 열려요. 채우기 전에는 잠겨 있어요.
- **포토카드 뽑기**: 하루 1장. 일반 70% · 레어 25% · 슈퍼레어 5%, 아직 없는 카드가 먼저 나와요. 카드는 김결 탭 바인더에 모여요. 마음에 안 드는 카드는 '숨기기'로 빼요.
- **기념일 한정 카드**: 김결 생일·데뷔일, 김결 카테고리 일정이 있는 날 목표를 채우면 레어 이상 + 한정 표시 카드가 나와요.
- **새 영상**: @Gyeol_Kim 채널에 최근 2주 안에 올라온 안 본 영상. 알림에도 '새 영상 N개 잠김'이 붙어요.
- **숏츠 피드**: 김결 숏츠를 위로 넘기며 앱 안에서 봐요.
- **추억 영상 뽑기**: 하루 1번, 예전 영상 하나를 골라 줘요.

## 김결 탭
프로필(함께한 날, 생일·데뷔 D-day), 오늘의 보상, 포토카드 바인더, 뽑은 추억 영상, 덕질 기록장(공연·앨범·팬사인회 등, 사진 첨부 가능. 기록을 누르면 수정·사진 바꾸기·삭제)이 있어요.

## 일정 카테고리
- **설정 → 일정 카테고리**에서 카테고리를 추가하고, 눌러서 이름과 색상을 바꿀 수 있어요. 일정 추가 화면의 '카테고리·색상 관리'로도 갈 수 있어요.
- 기본 카테고리인 '내 일정'과 '가수 일정'은 지울 수 없어요. 가수 일정은 색상만 바꿀 수 있고, 이 색이 D-day 카드에도 쓰여요.
- 카테고리를 지우면 그 카테고리의 일정은 '내 일정'으로 옮겨져요.
- **할 일**: 오늘 할 일 목록과 할 일 달력이 있어요.
  - 목록에는 오늘 할 일(오늘 마감, 이월된 일, 기간 중인 일, 날짜 없는 일)과 오늘 끝낸 일만 보여요. 앞으로의 할 일은 달력에서 봐요.
  - **전체 / 진행 중 / 이월 / 완료**로 나눠 볼 수 있어요. 전체에서는 끝낸 일이 줄이 그어진 채 맨 아래에 보여요.
  - **할 일 달력**: 날짜마다 ✓ 완료, ✕ 못 끝냄, ● 할 일 개수가 보여요. 날짜를 누르면 그날 끝낸 일·못 끝낸 일·할 일 목록이 뜨고, 오늘과 앞으로의 날짜에는 바로 할 일을 추가할 수 있어요.
  - 마감일은 기본으로 오늘 날짜가 들어가 있고, 누르면 미니 달력에서 고를 수 있어요. 아래의 오늘·내일·3일 후·일주일 후 버튼으로 빨리 고를 수도 있어요.
  - **여러 날에 걸쳐 하는 일**에 체크하면 시작일~마감일 기간으로 정할 수 있어요. 기간 중에는 매일 홈과 '오늘' 목록에 '~마감일 · D-n'으로 보이고, 시작일 전에는 달력에서만 보여요. 오늘 목표에는 마감일 당일에만 들어가요.
  - 마감일까지 못 끝낸 일은 다음 날 자동으로 오늘로 넘어오고 'N일째 이월' 표시가 붙어요.
  - 할 일은 내가 정한 순서대로 보여요. 오른쪽 ≡를 꾹 누른 채 끌어서 순서를 바꾸고, 수정 화면의 '맨 위로'로 한 번에 올릴 수도 있어요. 새 할 일은 맨 뒤에 붙어요.
  - 할 일을 누르면 이름·마감일·프로젝트를 바꾸고, 상세 내용과 완료 후 메모를 적을 수 있어요. (프로젝트에 빼먹은 할 일도 나중에 넣을 수 있어요)
  - 할 일을 추가할 때도 상세 내용을 바로 적을 수 있어요.
  - 프로젝트 세부 할 일은 프로젝트 화면 위쪽의 **+ 추가**로 넣어요. 추가 창은 닫히지 않아서 같은 날짜로 여러 개를 이어서 넣을 수 있어요. 할 일 목록과 홈에는 마감일 당일에만 떠요. 마감까지 못 끝내면 일반 할 일처럼 다음 날로 넘어오고 'N일째 이월'이 붙어요.
  - **하루 루틴**: 홈의 '오늘의 루틴'에서 체크하고, **관리**에서 만들고 고쳐요. 관리 창에 최근 7일 기록이 점으로, 연속 기록이 🔥로 보여요. 루틴은 할 일과 따로 세서 오늘 목표·보상에는 들어가지 않고, 하나에 +5점이에요.

## 점수 규칙
- 할 일 완료: +10점
- 마감 전(또는 당일)에 끝내면: +5점 추가 (이월된 일은 제외)
- 프로젝트의 세부 할 일을 모두 끝내면: +50점 (프로젝트당 한 번)
- 하루 목표를 채운 날이 이어지면 🔥 연속 기록이 올라가요.

## 코드를 고친 뒤 폰에 반영하기
1. `sw.js` 맨 위 `CACHE = 'gyeolsim-v1'`의 숫자를 올려요 (v2, v3 …).
2. 바뀐 파일을 GitHub에 다시 올려요.
3. 폰에서 앱을 완전히 닫았다가 다시 열면 새 버전이 적용돼요.

## 데이터 관련 주의
- Safari의 **방문 기록 및 웹사이트 데이터 지우기**를 하면 기록이 사라질 수 있어요.
- **설정 → 백업 내보내기**로 가끔 JSON 파일을 '파일' 앱에 저장해 두세요. 폰을 바꿀 때도 **백업 불러오기**로 옮길 수 있어요.

## 앱 이름·아이콘을 바꿨을 때
아이폰은 홈 화면에 추가할 때의 이름과 아이콘을 그대로 기억해서, 코드를 바꿔도 이미 추가된 아이콘은 바뀌지 않아요.
**홈 화면 아이콘을 지우면 그 앱의 데이터도 함께 지워지니까** 꼭 아래 순서대로 하세요.
1. 앱에서 **설정 → 백업 내보내기**로 백업 파일을 '파일' 앱에 저장해요.
2. 홈 화면의 기존 아이콘을 삭제해요.
3. Safari로 앱 주소를 열고 **공유 → 홈 화면에 추가**를 다시 해요.
4. 새 아이콘으로 앱을 열고 **설정 → 백업 불러오기**로 1번 파일을 불러와요.

## 코치 알림
- **설정 → 코치 알림 🔔 → 알림 켜기**로 켜요. 홈 화면에 추가한 앱(iOS 16.4 이상)에서만 돼요.
- 알림 받을 시간에 그날 아직 안 끝낸 할 일 이름을 넣은 코치 말이 와요. 할 일이 없으면 안 와요.
- **다가오는 일정 알림** (설정에서 끌 수 있어요): 종일 일정과 아침 9시 전 일정은 전날 밤 10시, 오전 일정은 그날 아침 8시, 오후 일정은 그날 오전 11시에 와요. 같은 시각의 일정은 한 알림에 묶여요.
- 앱을 열거나 할 일·일정을 바꿀 때마다 알림이 다시 예약돼요. 코치 알림은 오늘·내일, 일정 알림은 앞으로 일주일 치를 예약해요(서버 한도 30개). 서버가 5분마다 확인해서 보내요. 일정 알림과 같은 시각의 코치 알림은 빠져요.
- 알림 서버: `push/` 폴더 (Cloudflare Worker `gyeolsim-push`, https://gyeolsim-push.kboram28.workers.dev).
  - 서버 코드를 고쳤을 때: `push` 폴더에서 `npx wrangler deploy`
  - 서명용 비밀 키(VAPID_PRIVATE_JWK)는 Cloudflare에만 저장돼 있어요. 다시 만들면 `index.html`과 `push/worker.js`의 공개 키도 바꾸고, 폰에서 알림을 껐다 다시 켜야 해요.
